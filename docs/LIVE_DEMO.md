# Live StudioNet two-stage demonstration

This is a public, test-only execution of MilestoneBond v0.2. It uses simulated StudioNet GEN; it is not a production escrow or security audit. The [app](https://demigodd00.github.io/milestonebond/) reads the [new contract](https://explorer-studio.genlayer.com/contracts/0xb437593b7656254226ce496bc6f9A052A11D6345). The [machine-readable verification record](https://demigodd00.github.io/milestonebond/verification.json) was regenerated from finalized onchain state and receipts, not from the local walkthrough.

The sponsor froze [issue #1](https://github.com/Demigodd00/milestonebond/issues/1), the repository identity, base commit `94d80d7b2eab03baff1c65b55216aa31eb98f652`, the unchanged workflow, two criteria, a fixed author and two 0.001 test-GEN tranches. The author submitted [PR #2](https://github.com/Demigodd00/milestonebond/pull/2) on commit `83b5c6d7b6170a6431635ce45aeb25376c5d66c4` with [passing CI run 38197462942](https://github.com/Demigodd00/milestonebond/actions/runs/38197462942). Only after that stage settled did the author publish [PR #3](https://github.com/Demigodd00/milestonebond/pull/3), direct-child commit `f616f7e404d61a85e75513438172d0cf31089209`, and [passing CI run 38198377989](https://github.com/Demigodd00/milestonebond/actions/runs/38198377989). The contract checked that the second CI run started after stage two opened.

The initial v0.1 deployment is retained in [history](../deployments/history/studionet_v0.1.json). Its [first project-creation attempt](https://explorer-studio.genlayer.com/transactions/0x8e5096c17660a2b6ffb6fd8145ad8fbfcad21f943b8ba0c835319e2d5c24ce33) finalized with an execution error: the full GitHub response for the repository’s initial commit was about 130 KB, above the 100 KB fetch cap. The v0.1 contract’s accounting remained all zero. v0.2 fixed registration by using GitHub’s 934-byte commit-metadata endpoint and was separately deployed; the old contract was not silently replaced. A later withdrawal attempt received an HTTP 504 during `eth_estimateGas`, **before** any transaction hash or state change, and a single subsequent retry produced the successful withdrawal above.

The direct tests use mocks. The live receipts above show actual hosted StudioNet execution and validator votes, including one dissent on stage two; they do not imply unanimity, production safety, or that GitHub CI independently proves semantic correctness. GitHub repository control, CI dependencies, validator availability and sponsor-authored criterion quality remain external dependencies.
